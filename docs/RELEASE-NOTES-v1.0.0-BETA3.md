# Veiga's S3CC Manager v1.0.0 Beta 3

Beta 3 is a reliability, classification and interface refinement release compared with Beta 2.

## Compared with Beta 2

- Reconciles legacy package folders with the canonical Manager hierarchy while preserving valid loading branches and protecting non-empty folders.
- Uses broader Store and official-resource evidence for Sets, Items and Premium Content, while keeping partial overlaps as diagnostics instead of unsafe automatic moves.
- Improves recognition of CAS replacements, eyelashes, roofs, gameplay companions, sliders and grouped mod content.
- Strengthens exact-duplicate keeper selection and quarantine planning, including already-quarantined files and explicit safety blocks.
- Reuses valid scanner, classification, Store and independent analysis cache data with correct invalidation after relevant changes.
- Adds on-demand polycount details for supported GEOM/MLOD/MODL resources and preserves diagnostic explanations when parsing is unavailable.
- Refines Organizer, Duplicates and Conflicts selection, filtering, status feedback and localized PT / EN / ES presentation.
- Aligns the final language/theme controls and improves EA App SearchBox contrast in normal, hover and focus states.

Beta 3 preserves the Beta 2 safety guarantees. Packages with insufficient evidence, unresolved collisions or unsupported destinations remain available for review and are not moved automatically.

This is a testing release. Back up important Mods folders before testing write operations and review the Before → After plan before organizing files.
